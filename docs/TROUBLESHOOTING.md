# 故障排查（校园网自动登录 2.0）

先做两件事：打开仪表盘看顶部状态横幅；点「复制诊断信息」把信息拿到手。
下面按症状给出处理办法。

## 1. 状态一直是「未配置 / 还没保存账号密码」

账号密码没保存或保存失败。在「账号」卡片重新填写后点 **保存账号密码**。
如果提示保存失败，检查 `%LOCALAPPDATA%\CampusNet\` 是否可写（例如被安全软件锁住）。

## 2. 状态是「在线」但实际打不开网页

程序判断「在线」的依据是能 TCP 连通几个公网目标。如果你所在网络只放行部分目标，
可以在「高级设置」里或直接改 `config.json` 的 `ProbeTargets`，换成你确定能通的地址，例如：

```json
"ProbeTargets": ["tcp:223.5.5.5:443", "tcp:114.114.114.114:53", "tcp:www.msftconnecttest.com:80"]
```

格式为 `tcp:主机:端口` 或 `icmp:主机`。

## 3. 状态是「连不上校园网，等待网络恢复」

说明本地探测和 Portal 都不通。这时候程序不会去登录（登录也没用），会每 5 秒重试。检查：

- 网线是否插好 / Wi-Fi 是否连上；
- 是否连到了错误的网络（例如手机热点或其它 Wi-Fi）；
- 本机是否开着会拦截流量的代理软件（Clash、VPN 等）。程序自身访问 Portal 时已显式绕过系统代理，
  但代理的 TUN 模式仍可能影响局域网访问。

## 4. 状态是「本机探测不通，但 Portal 显示账号在线」

这是上游异常（Portal 认为你在线，但实际数据出不去），常见于校园网侧故障或网卡驱动异常。
程序会转成每 5 分钟复查一次，不会重复登录顶掉自己的会话。
可以手动试试点「立即重连」，或重插网线 / 重启网卡。

## 5. 状态是「冷却中」

两种原因，都在仪表盘的「冷却」和日志里写明了：

- **Portal 明确限流（请求过于频繁）**：说明短时间内请求太多。程序会冷却 30 分钟，期间只探测不登录；
- **重复认证冲突**：Portal 提示账号已在别处在线，但本机复检又不在线（常见于账号被其它设备占用）。
  程序同样进入 30 分钟冷却，避免两台设备反复互相顶号。

冷却时间可以在 `config.json` 里用 `LoginCooldownMinutes` 调整（设为 `0` 表示不限流冷却，不建议）。

## 6. 登录失败，日志里有 `Msg=…` 与错误码

程序会把 Portal 返回的 `msga` 送到错误码接口翻译成中文，常见含义：

| 错误码 | 提示 | 处理 |
| --- | --- | --- |
| `userid error1` | 账号不存在 | 账号写错了，或不在该认证域 |
| `userid error2` | 密码错误 / 账号已在线 | 先确认密码；如果密码没错，就是账号被占用（见上一节） |
| `error5 waitsec <3` | 请求过于频繁 | 刚注销完又立刻登录，等几秒 |
| `Error code: 205` | System Error1 | 多为请求过于频繁，程序会冷却 |

## 7. 杀毒软件 / SmartScreen 拦截

exe 是用仓库源码现场编译、没有数字签名的程序，火绒、Defender 可能首次运行就拦。
处理办法：在拦截提示里选择「允许 / 信任」；火绒可以在「防护中心 → 信任区」把
`CampusNet.exe` 或 `%LOCALAPPDATA%\Programs\CampusNet\` 加进白名单。

## 8. 开机后没有自动运行

检查三点：

1. 仪表盘的 **开机自动运行** 勾选框是勾上的；
2. 注册表 `HKEY_CURRENT_USER\Software\Microsoft\Windows\CurrentVersion\Run` 里存在 `CampusNet` 项；
3. 任务管理器的「启动」页里 `CampusNet` 没有被禁用。

如果之前用「绿色版」直接运行，自启项指向的是那个临时路径，移动文件后需要重新勾一次自启（或点一次「安装」）。

## 9. 想临时停止自动登录

托盘右键 → **暂停 30 分钟**（到点自动恢复），或者托盘右键 → **退出**（不自动恢复，需要手动打开）。

## 10. 彻底卸载

仪表盘点 **卸载**：会关闭开机自启、删除快捷方式，并移除安装目录里的 exe（数据默认保留）。
要连数据一起删，卸载后手动删除 `%LOCALAPPDATA%\CampusNet\` 即可。

## 11. 需要更深入的排查

```powershell
# 当前状态一行行打印
CampusNet.exe --status

# 完整诊断（版本、路径、网络、配置、状态、旧版残留、日志尾部）
CampusNet.exe --diagnose --with-log

# 前台跑一轮完整检查（会真实探测，必要时登录）
CampusNet.exe --once

# 界面自检：构建窗口、刷新一次后退出
CampusNet.exe --selftest
```

日志文件：`%LOCALAPPDATA%\CampusNet\login.log`（超过 5 MB 自动滚动为 `login.log.old`）。
协议层面的细节（接口、字段、编码、错误码来源）见 [Dr.COM ePortal 协议说明](DRCOM-PROTOCOL.md)。
