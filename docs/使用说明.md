# 使用说明（校园网自动登录 2.0）

这一份是给使用者看的，不需要懂技术，照着做一遍就行。

## 一、安装

1. 打开 [Releases](../../releases)，下载 `CampusNet-v2.0.0.exe`（2.0 的发布只有这一个文件；
   附件名里的版本号和标签名一致，例如标签 `v2.0.0` 对应 `CampusNet-v2.0.0.exe`）。
2. 双击下载到的那个 exe（文件名里带版本号不影响使用，不用改名再运行）。
   - 如果弹出蓝色的「Windows 已保护你的电脑」，点 **更多信息** → **仍要运行**。
     这是因为程序没有购买数字签名证书，不是病毒。
   - 如果杀毒软件（例如火绒）拦截，选择 **允许 / 信任** 即可。
3. 窗口打开后，在右边「账号」卡片里填：
   - **账号**：校园网账号（学号）
   - **密码**：校园网密码
   然后点 **保存账号密码**。密码会被 Windows 加密保存，只有你这台电脑的这个用户能解开。
4. 点 **安装**，程序会：
   - 复制到 `C:\Users\<你的用户名>\AppData\Local\Programs\CampusNet\CampusNet.exe`
   - 在开始菜单创建「校园网自动登录」快捷方式
   - 开启开机自启（下次开机登录 Windows 后会自动运行）
5. 点 **关闭窗口（后台继续运行）**，或者直接点右上角的 ×。
   程序不会退出，而是缩到右下角托盘里继续守着。

## 二、日常怎么用

- **不用管它**：网络正常时它只做本地探测（并核对网页内容是不是真的能打开），几乎不发任何请求；
  掉线了会自动帮你登录。
- **看状态**：鼠标放到右下角托盘图标上看提示，或者双击图标打开仪表盘。
  - 🟢 绿色 = 网络正常
  - 🟡 黄色 = 网络异常，正在重连
  - 🔴 红色 = 需要处理（例如还没填账号密码）
  - ⚪ 灰色 = 已暂停
- **网络卡住不想等**：托盘右键 → **立即重连**，程序会注销当前会话再重新登录一次。
- **想临时停下**：托盘右键 → **暂停 30 分钟**，30 分钟后自动恢复；也可以点仪表盘上的「暂停」。
- **彻底退出**：托盘右键 → **退出**（会问一次「确定要退出吗」）。退出后网络断了不会自动重连。
- **不用管它有没有崩**：程序会顺手多起一个独立的守护小进程，每 30 秒看一次，
  万一崩了或卡死了会自动把它拉回来（守护自己的动作记在 `watchdog.log` 里）。
  你在托盘里点「退出」时它也会一起收工，不会偷偷把程序又拉起来。

## 三、常见问题

**Q：重启电脑后会自动运行吗？**
会。只要安装时开启了「开机自动运行」，登录 Windows 后程序会自己起来并缩在托盘里。

**Q：能不能放进 U 盘带走？**
可以。exe 是单文件绿色程序，放到任何地方双击都能用，只是「开机自启」要重新点一次。

**Q：之前装过 1.x 的 PowerShell 版本，怎么办？**
打开 2.0，右侧「程序」卡片会提示检测到旧版残留，点 **清理旧版残留**，
确认一次 UAC 弹窗（管理员确认）即可删掉旧的计划任务和脚本。旧的账号密码需要重新输入。

**Q：怎么知道它到底有没有在工作？**
仪表盘上的「运行统计」会显示最近探测时间、本小时登录次数、下次探测倒计时，并且每次掉线、
登录、失败都会记进「运行日志」。最近探测时间不停在更新，就说明它在正常工作。

**Q：会不会因为请求太多被学校封号？**
正常上网时程序**一个登录请求都不发**：只做本地探测（取回指定网页文本 + TCP/ICMP 兜底），
外加默认每 2 分钟一次**只读**的会话核对。只有确认网络真的不通时，才会去查 Portal 状态并登录；
而且两次登录至少间隔 60 秒、每小时最多 12 次。如果 Portal 明确提示限流，它会记下原因并停止本轮重试，
等过了最小间隔再按节奏尝试，绝不会连环狂刷。

**Q：为什么以前会「一直显示在线，其实已经掉线了」？**
有的校园网关会替任意 TCP 连接代答握手（连不存在的地址也显示 0 ms 连上），只看「能不能连上」
会被骗。2.0.0-pre.3 起改成**内容校验**：必须真的取回指定网页里的文本才算在线；
一旦内容校验没过，就立刻向 Portal 求证并重新登录。所以托盘不会再一直骗你「在线」。

**Q：被踢下线后多久能恢复？**
分两段看：**发现**掉线 + **重连**。

- 重连本身很快：探测目标**同时**跑（整轮耗时约等于单条目标的超时），HTTP 目标有独立的 3 秒超时，
  确认不通后先做一次**纯本地内容校验**（本地其实能上网就跳过登录，连 Portal 都不查），
  再等 **1 秒**做二次确认、提交登录——「发现离线 → 提交登录」通常只要 1 秒左右。
- 发现掉线是主要开销。2.0.0-pre.9 把三条路径都提速了：定时会话核对默认 **每 2 分钟**一次；
  「内容校验没过」的疑似掉线复核改成**至少间隔 20 秒**；插拔网线 / 切换 WiFi / IP 变化会**立刻**触发复检。
  实测掉线发现时间从旧版的中位 166 秒降到约 40~60 秒，绝大多数情况 1 分钟内就会开始重连。
- 登录提交之后也有提速：先**立刻**做一次本地内容校验（0 延迟、不发 Portal 请求），
  再按 **+2 / +5 / +9 / +14 / +20 / +23 秒**加密复检（每档只发一次只读 `chkstatus`）。
  本机 50 次自然掉线实测：旧阶梯下 29 次都拖到 +20 秒才确认，加密后中位约 +14 秒。
  如果此时还处在「两次登录至少间隔 60 秒」的等待期，它不会干等，
  而是**每 5 秒只做本地探测**（这段一个 Portal 请求都不发），网络一恢复就立刻确认——
  网络能上网之后最多约 8 秒内就会显示回到在线。

想更快可以把「高级设置 → 会话校验间隔」调到 60 秒左右（代价是 Portal 只读请求变多），
或者把「HTTP 探测超时」调小一点（调小更快、调大更稳）。

**Q：仪表盘上「登录已提交，等待确认」是什么意思？**
登录请求发出去了，但 Portal 的状态接口刚好不可达，程序**无法确认**到底有没有联上网。
这种情况下它不会假报成功，而是按异常节奏继续复检，恢复后自动转为「在线」。

**Q：提示「配置文件损坏」或「探测目标配置无效」怎么办？**
这两种情况程序会**停止自动登录**并给出提示（红色），这是故意的：配置读失败时继续登录，
有可能把账号密码发到默认地址去；探测目标全写错时程序根本没法判断网络状态。
按提示修好 `config.json`（或在界面上改任意一项高级设置保存一次）即可恢复。

**Q：用命令行怎么保存账号密码？**
密码不能写在命令行里（会留在 PowerShell 历史和进程列表里）。用
`CampusNet.exe --set-credentials 你的账号`（会提示输入、不回显）或
`'密码' | CampusNet.exe --set-credentials 账号 --password-stdin`；最省事还是在界面里填。

**Q：我在两台设备上用同一个账号，会不会互相顶？**
程序在登录前会先查状态，只有 Portal 明确显示「未在线」才提交登录。如果 Portal 提示
「账号已在别处在线」或「密码错误」（`userid error2` 这类），程序会**完全忽略这个提示**：
只记一行日志和「已忽略提示」计数，不当成失败，然后做几次轻量复检——复检发现网络其实通了
就当成功；确实不通就按最小间隔 60 秒、每小时最多 12 次的节奏继续尝试。

**Q：把 `RetryCount` 调大，会不会绕过「最小间隔」连环登录？**
不会。`RetryCount` 只决定「一次触发里最多提交几次登录」，而且每次提交前都要重新过一遍
最小间隔（默认 60 秒）和每小时上限（默认 12 次）。默认值 1 就是「一次触发只提交一次」。
如果一次流程里发现最小间隔还没到，它会直接停下，把机会留给正常节奏。

**Q：学校要求密码用 MD5 加密提交（`en_md5=1`），能用吗？**
不能。本工具目前只按明文提交，相当于 `en_md5=0`。如果学校强制 `en_md5=1`，
登录会一直失败——日志里会出现一行对应的提示，这种情况请换用学校官方的客户端。

**Q：日志和状态文件里会不会写着我的密码？**
不会。从 2.0.0-pre.8 起，写进 `login.log`、`state.json`、界面诊断和剪贴板的所有文本
都会先脱敏：密码一律变成 `***`，账号只保留前三位（例如 `251******`）。
`credentials.dat` 里的密码是 Windows DPAPI 加密的，只有你这台电脑的这个用户能解开。

**Q：点了「卸载」之后会怎么样？**
程序会关掉开机自启、停掉守护、删掉开始菜单快捷方式，把安装目录里的 exe 排入删除队列，
然后**自己退出**——正在运行的 exe 是删不掉的，所以交给一个独立的小进程在它退出后删；
万一还被安全软件占用，会在**下次重启后**自动消失。数据目录默认保留（需要连数据一起删，
用 `CampusNet.exe --uninstall --delete-data`，或卸载后手动删除数据目录）。

**Q：电脑上显示「在线」，其实上不了网，它会自己处理吗？**
会。本机探测连续 60 秒不通、但 Portal 坚持说账号在线时（典型的残留会话挡路），
程序会自动**注销一次再重新登录**，等同于你手动点「立即重连」。
这个秒数可以在「高级设置 → 残留会话自动重登」里改（`0` = 关闭）。

**Q：日志太大了怎么办？**
仪表盘「运行日志」卡片右上角有 **清空日志** 按钮，点一下确认即可清空 `login.log` 与 `login.log.old`
（命令行等价写法：`CampusNet.exe --clear-log`）。

**Q：数据都存在哪？怎么彻底删掉？**
`C:\Users\<你的用户名>\AppData\Local\CampusNet\`。
在仪表盘点「打开数据目录」可以直接看到。卸载时数据默认保留，可以手动删除这个目录。

## 四、出问题了怎么办

1. 打开仪表盘，点 **复制诊断信息**（把版本、网络、配置、状态、日志尾部一起复制到剪贴板）。
2. 把它粘贴到求助的地方。
3. 更多情况见 [故障排查](TROUBLESHOOTING.md)。
