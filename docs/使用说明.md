# 使用说明（2.2.0-pre.1）

## 安装与升级

从 Releases 下载最新的 **CampusNet-v2.2.0-pre.1.exe**。运行环境为 Windows 10/11 和 .NET Framework 4.8，无需另装 .NET 8 运行时。

1. 先对照 SHA256SUMS.txt 核对下载文件。
2. 若正在运行旧版，从托盘菜单选择「退出」，保留原有配置和数据目录。
3. 双击新 EXE。已有 2.x 配置和 DPAPI 凭据可继续读取；首次使用在「账号」卡片保存账号密码。
4. 需要长期运行时，点「安装」更新用户目录中的程序并设置自启；关闭窗口后程序继续在托盘运行。

程序未签名，可能触发 SmartScreen。运行前确认来源及校验值。密码保存在 credentials.dat 中，使用当前 Windows 用户的 DPAPI 加密；换用户或机器时应重新保存凭据。

## 日常操作

- 「立即重连」会先检查有效凭据、暂停状态、登录间隔和小时上限，通过后才注销重登。限频期间不会先断开当前会话。
- 「暂停」取消进行中的恢复流程，暂停期间不再自动提交；「恢复自动登录」重新开始检查。
- 「刷新」立即检查网络；「复制诊断信息」复制版本、网络、配置和脱敏状态信息。
- 从托盘「退出」停止主程序和守护进程；关闭主窗口则继续后台运行。
- 「高级设置」保存后立即生效，重载保留本次运行的登录计数。

## 恢复需要多久

分成发现异常、提交登录、验证恢复三段。默认在线探测每 20 秒、异常探测每 5 秒、周期会话核对每 120 秒；登录前保留 1 秒确认，实际耗时还包括请求时间。网卡或 IP 变化会在 1 秒防抖后唤醒检查。

登录响应返回后，进入 30 秒观察窗口，立即校验内容，之后每 2 秒安排一次单轮校验。Portal 独立在第 2、5、9、14、20、23 秒查询，最多六次。内容验证通过即确认联网，无需等待慢 Portal。

窗口结束后继续按异常频率监视。默认两次登录间隔 60 秒、每小时最多 12 次；这些限制不会让本地检查一起停下来。全部探测失败但会话在线时，300 秒仅限制该分支的 Portal 查询，本地仍按异常频率检查。

模拟验收条件为默认超时、成功目标响应不超过 200 毫秒：可验证后观察窗口内 4 秒、后续等待期 6 秒内确认。真实校园网改善需通过自然掉线样本验证。

## 怎样看状态

配置了 HTTP 内容目标时，必须返回预期文本或状态码，才显示「联网验证通过」。Portal「会话在线」仅表示认证状态，不能证明外网已通。

仅配置 TCP/ICMP 的旧配置需要传输探测和 Portal 会话同时在线，显示「未验证内容」。建议保留默认 HTTP 内容目标，以识别网关代答 TCP 握手。

「登录已提交，尚未确认联网」表示请求已发出，内容仍未验证通过；程序继续监视。Portal 超时或状态滞后不会挡住成功的内容验证。

持续达到残留会话阈值（默认 60 秒）且 Portal 仍在线时，程序会在限频允许后自动注销重登一次。同一次故障未实际恢复前不会反复注销。

## 次数和耗时

仪表盘显示本小时登录次数；「今日登录」「恢复耗时」两行仍为占位。实际数据在 login.log：

- 「恢复计时：首次发现联网异常」：程序第一次观察到异常，不能作为真实断网时刻。
- 「恢复计时：提交登录」：距本次异常开始计时经过多久。
- 「登录接口返回耗时」：POST 请求耗时。
- 「提交 → 确认耗时」：提交到验证通过的实际经过时间。

提交计数在发送前持久化，以免重启丢失限频依据。进程在保存后、发送前被打断时，可能保守多占一次额度。

## 数据与排障

数据目录仍为 %LOCALAPPDATA%\CampusNet；界面「打开数据目录」可查看 config.json、state.json、login.log、credentials.dat 等。

- 业务提示保留 Msg/msga 原文。error2 在不同学校可能含义不同，不能单凭它断定密码错误、账号占用或加密模式。
- 本版继续使用现有明文表单协议，强制 en_md5=1 的学校仍需专门适配。
- 配置损坏或没有合法探测目标时停止自动登录，修好配置后恢复。
- 「清除显示」仅清空窗口中的日志；命令行 --clear-log 才删除历史日志文件。
- 单文件可便携运行。安装、卸载、1.x 清理等功能仍保留；卸载默认保留数据。
- 日志和诊断会脱敏；分享时不要附上 credentials.dat。

更多内容见 [故障排查](TROUBLESHOOTING.md)、[README](../README.md)。
